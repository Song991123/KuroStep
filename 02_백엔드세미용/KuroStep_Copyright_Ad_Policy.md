# KuroStep Copyright And YouTube Ad Policy

이 문서는 `저작권보호심의 제도와 동향 25년 3호_김원 위원.pdf`를 참고해 KuroStep의 유튜브 재생, 광고, 가사 처리 방향을 정리한다.

## 참고 자료 핵심

- 2024년 저작권보호심의위원회에서는 유튜브 영상 또는 음원을 앱 내에서 임베디드 링크 방식으로 스트리밍하거나 다운로드하도록 제공한 앱들이 검토되었다.
- 일부 앱은 유튜브 광고를 제거하고 자체 광고를 노출하거나, 광고 제거 기능을 유료 판매한 것으로 소개되었다.
- 자료는 광고 제거 행위가 YouTube, LLC의 광고 영업 이익을 침해하거나 성과물 도용의 부정경쟁행위 및 불법행위로 평가될 가능성이 크다고 설명한다.
- 기술적 보호조치 우회, 다운로드, 광고 제거, 광고 수익 대체는 특히 위험한 구현으로 본다.
- 링크 자체는 중립적인 기술이지만, 침해를 충분히 인식하고 영리적ㆍ계속적으로 접근을 쉽게 만드는 행위는 법적 문제가 될 수 있다.

## KuroStep 구현 원칙

1. YouTube 영상 또는 음원 다운로드를 구현하지 않는다.
2. YouTube 광고 제거, 광고 스킵 자동화, 광고 우회를 구현하지 않는다.
3. YouTube 광고를 자체 광고로 대체하지 않는다.
4. YouTube 공식 IFrame Player API 또는 사용자가 직접 제공한 공식 URL 기반 재생만 검토한다.
5. 재생은 작업 맥락 보조 기능으로 두고, 음원 제공 서비스처럼 설명하지 않는다.
6. 서버 DB에는 음원 파일, 영상 파일, 가사 전문을 저장하지 않는다.
7. 가사 원문은 공식/허용 Provider 응답을 사용하고, 필요한 경우 사용자 로컬 파일로 관리한다.

## 광고 발생 시 처리 방침

공식 IFrame Player API는 광고 시작/종료 이벤트를 안정적으로 제공하지 않는다. 따라서 광고를 감지해 자동으로 음소거하거나 스킵하는 기능은 구현하지 않는다.

허용하는 사용자 제어:

- 사용자가 직접 재생/정지
- 사용자가 직접 음소거
- 사용자가 직접 볼륨 조절
- 사용자가 직접 다음 곡 이동
- 사용자가 직접 재생바 이동
- 사용자가 직접 `YouTube 영상 보기`를 눌러 공식 YouTube iframe을 펼치고, 광고가 보이면 직접 스킵 또는 조작

허용하지 않는 자동화:

- 광고 DOM 탐지
- 광고 스킵 버튼 자동 클릭
- 광고 구간 자동 음소거
- 광고 재생 시간을 강제로 끝으로 이동
- 광고 없는 재생을 보장하는 기능 또는 문구

## 세미 발표 표현

사용 가능한 표현:

> KuroStep은 YouTube 공식 IFrame Player API 기반으로 앱 내 재생 상태를 제어하고, 현재 재생 시간에 맞춰 가사와 번역 메모를 동기화하는 작업 보조 위젯을 목표로 한다.

피해야 할 표현:

> 광고 없는 유튜브 플레이어를 구현했다.

> 유튜브 광고를 자동으로 스킵한다.

> 유튜브 음원을 앱에서 추출해 재생한다.

## 최종 판단

KuroStep의 안전한 방향은 `공식 재생 + 커스텀 작업 UI + 사용자 제어 + 가사/번역 메모 관리`이다.

광고 제거, 다운로드, 스트림 추출, 광고 자동 스킵은 이번 세미 범위에서 제외하고 트러블슈팅 및 법적 리스크 검토 항목으로 기록한다.

## 현재 검증한 UI 방향

- 평소에는 YouTube iframe 컨테이너를 접고 KuroStep 커스텀 플레이어, 재생바, 가사/번역 메모만 보여준다.
- 사용자가 `YouTube 영상 보기`를 누르면 같은 iframe 컨테이너가 아래로 펼쳐져 공식 YouTube 플레이어가 보인다.
- 광고가 발생하면 앱이 자동으로 건드리지 않고, 사용자가 펼쳐진 YouTube 화면에서 직접 조작한다.
- iframe을 다시 접어도 같은 YouTube Player API 인스턴스를 유지하므로 재생 시간, 재생바, 가사 라인 싱크가 계속 이어진다.
