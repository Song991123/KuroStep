# Features

## 1. Auth / Security

| 기능 | 구현 상태 |
|---|---|
| 회원가입 | 완료 |
| 로그인 | 완료 |
| BCrypt 비밀번호 암호화 | 완료 |
| JWT 발급 및 검증 | 완료 |
| 사용자별 리소스 검증 | 완료 |

인증은 Spring Security + JWT 기반으로 구성했습니다. API 요청 시 토큰을 검증하고, Service 계층에서 `userId` 기준으로 작업 카드, 플레이리스트, 번역 메모의 소유권을 확인합니다.

## 2. 작업 카드

| 기능 | 구현 상태 |
|---|---|
| 오늘 작업 조회 | 완료 |
| 작업 카드 생성/수정/삭제 | 완료 |
| 작업 상태 변경 | 완료 |
| 상태별 카운트 | 완료 |

작업 상태는 `TODO`, `DOING`, `DONE`으로 관리합니다. 프론트에서는 실제 작업 목록을 기준으로 상태 카운트를 계산하여 목록과 숫자가 어긋나지 않도록 보완했습니다.

## 3. BGM 바구니 / 플레이리스트

| 기능 | 구현 상태 |
|---|---|
| YouTube 단일 링크 등록 | 완료 |
| YouTube 플레이리스트 미리보기 | 완료 |
| 플레이리스트에 곡 추가/삭제 | 완료 |
| 드래그 앤 드롭 순서 변경 | 완료 |
| 셔플 | 완료 |
| 전체 반복 / 한 곡 반복 | 완료 |

YouTube 링크는 프론트에서 ID를 추출하고, 백엔드 `Track`과 `PlaylistTrack`으로 관리합니다. 플레이리스트에는 같은 곡이 중복 추가되지 않도록 제약을 두었습니다.

## 4. 가사 / 번역 메모

| 기능 | 구현 상태 |
|---|---|
| LRCLIB 가사 조회 | 완료 |
| 싱크 가사 파싱 | 완료 |
| 가사 라인 참조 생성 | 완료 |
| 현재 재생 위치 기반 가사 선택 | 완료 |
| 번역 초안 생성 | 완료 |
| 사용자 번역 메모 저장/삭제 | 완료 |

가사는 LRCLIB Provider에서 조회합니다. 서버에는 가사 라인 참조와 사용자 메모를 중심으로 저장하고, 클라이언트는 로컬 캐시를 활용해 반복 재생 시 불필요한 호출을 줄입니다.

## 5. Desktop / UI
