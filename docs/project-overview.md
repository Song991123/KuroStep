# 프로젝트 개요

## 🐾 프로젝트 소개

KuroStep은 재택 창작자가 작업할 때 쓰는 Todo, 작업용 BGM, 가사, 번역 메모를 하나의 작업 카드에 연결해 관리하는 데스크톱 작업 보조 서비스입니다.

일반 Todo 앱은 작업 항목만 관리하고, 음악 서비스는 재생만 담당합니다. 작업 중 떠오른 감정이나 가사 해석, 메모는 별도 문서나 메신저에 남기게 됩니다. KuroStep은 이렇게 흩어지는 정보를 `작업 카드`를 중심으로 다시 묶는 데 집중했습니다.

## 💡 해결하려는 문제

- 할 일과 작업용 음악이 따로 관리되어 작업 맥락이 끊긴다.
- 가사 해석이나 번역 메모가 여러 곳에 흩어져 다시 찾기 어렵다.
- YouTube 링크로 BGM을 틀기는 쉽지만, 가사와 메모를 함께 남기기는 어렵다.
- 작업 중에는 브라우저 탭보다 작게 고정해 둘 수 있는 위젯이 더 자연스럽다.

## 🔄 사용자 흐름

```text
로그인
-> 오늘 작업 카드 확인
-> YouTube 곡 또는 플레이리스트 등록
-> 작업 카드에 BGM 바구니 연결
-> 곡 재생
-> 현재 가사 확인
-> 가사 라인 선택
-> 번역 메모 저장
-> 작업 상태 변경
```

## ✅ MVP 범위

| 포함 | 설명 |
|---|---|
| 회원가입/로그인 | JWT 기반 인증 흐름 |
| 작업 카드 | 오늘 작업 CRUD, 상태 변경 |
| 곡/플레이리스트 | YouTube URL 기반 곡 등록, 플레이리스트 관리 |
| 가사 조회 | LRCLIB 기반 가사 조회와 줄 단위 관리 |
| 번역 메모 | 가사 줄별 번역 초안과 사용자 메모 저장 |
| 데스크톱 위젯 | Tauri shell + React UI |
| 배포 | GitHub Pages, AWS EC2, Docker Compose, Terraform |

## 📌 제외하거나 향후로 분리한 범위

| 항목 | 이유 |
|---|---|
| YouTube 다운로드/광고 우회 | 정책 리스크가 있어 공식 플레이어 기반으로 제한 |
| 정식 macOS notarization | Apple Developer Program이 필요해 포트폴리오 단계에서는 ad-hoc signing으로 처리 |
| 다중 Provider 가사 검색 | 현재는 LRCLIB 중심으로 구현했고, 향후 Provider fallback 확장 예정 |
| 협업 기능 | 개인 작업 보조 서비스 MVP에 집중 |
